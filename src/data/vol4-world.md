# Volume 4 — World Layer

## Core Principle

The World layer is the container everything lives inside — but never
passive. A good world: **constrains** (rules limit possibility, forcing
creative pressure), **reflects** (its condition mirrors protagonist's
internal state), and **pressures** (actively pushes back against the goal).
A world that just sits as backdrop is a structural problem, like a filler
scene.

### The Truth/Believed Gap (most powerful atom in this layer)
What the world's inhabitants believe about history/laws/institutions/places
vs. what's actually true — stored as separate fields on every major world
object. The gap is where dramatic irony, revelation, and theme live.

> **Theme boundary**: World layer = objective facts (what exists, what's
> possible, what happened — verifiable in-story). Theme layer = the meaning
> assigned to those facts. Atmosphere/tone/symbolic resonance is noted here,
> fully specified in Vol 5.

## World Identity & Scale

- World name/designation
- Scale — intimate (single building/household) / local / regional /
  national / global / cosmic
- Genre register — realistic / heightened realistic / historical /
  speculative / fantastical / hybrid
- Time period
- Dominant atmosphere (cross-ref Theme)
- The gap — distance between what world was and what it is now (wound at
  civilizational scale)

## Location Objects (sub-objects, one per significant location)

Same truth/believed gap structure applies to locations.

- Location ID and name
- Physical description — defining sensory features, not exhaustive
- Emotional register — what this place does to people who enter it
- **Official history** vs **True history**
- Truth status — verified true / verified false / deliberately ambiguous /
  unknown even to writer yet
- Who knows the truth (characters)
- Who benefits from the lie (characters/institutions)
- Location-specific rules — what's possible/impossible here that isn't elsewhere
- Symbolic weight (cross-ref Theme)
- State at story open / State at story close
- Story function — does it primarily constrain, shelter, threaten, or transform

## Laws

The hard rules. **A Law without a consequence for violation is not a Law —
it's a suggestion.** Consequence field is mandatory. Genre-agnostic —
covers physical, social, magical, institutional, economic rules equally.

- Law ID
- Plain language statement
- Law type — physical / social / political / technological / supernatural / economic / institutional
- Scope — universal / regional / cultural / specific characters only
- **Consequence for violation** (mandatory)
- Who enforces it — person / institution / natural force / world itself
- Exploitability — can it be bent/broken under specific conditions, at what cost?
- Known vs. true operation — how characters believe it works vs how it actually works
- Origin — where did it come from? Does anyone question it?
- Story function — constrains protagonist / enables antagonist / generates
  plot pressure / defines world's character

> **Exploitability is where plot lives.** The protagonist finding the edge
> case, the loophole, the price for breaking a rule everyone accepts — ask
> about this explicitly once enough character data exists.

## World as Character

When the world has sufficient dramatic agency (pushes back, resists,
decays, transforms intentionally), track it with character-adjacent atoms.
AI infers agency level from accumulated data — not all worlds need this.

- World's current condition (plain terms)
- The wound — what this world hasn't recovered from
- The want — what the world is moving toward or resisting
- Pressure on protagonist — how world's condition opposes/complicates their goal
- Dominant power — who benefits most from world remaining as-is
- World arc designation — transforms alongside protagonist / fixed as
  contrast / actively deteriorates

> **Cross-layer link**: A character's personal Lie is often a microcosm of
> the world's larger believed fiction. World revelation can trigger/mirror
> protagonist's internal reckoning — track this parallel; it's often the
> thematic spine.

## Historical & Mythological Records

Histories and myths share ONE object type — the story may not know (or may
deliberately withhold) which is which. Includes places too — a place's
official history vs. true origin uses this same object.

- Record ID and title
- Type — historical event / founding myth / religious narrative / folk
  legend / institutional origin story / cultural memory
- The told version
- The true version (can be "unknown even to writer")
- Truth status — verified true / verified false / deliberately ambiguous /
  unknown even to writer yet
- Who knows the truth — how, and whether they speak it
- **Who is invested in the lie** — who benefits from told version
  persisting; their investment level and what they'd do to protect it
- Living impact — how this actively shapes present behavior/politics/belief/law
- Revelation potential — plot point, theme point, or both? When/how might it surface?
- Connected locations — places whose identity ties to this record
- Story function — explains a Law / justifies power structure / fuels a
  character's wound / sets up a revelation

> **"Who is invested in the lie" is where world-building becomes plot.** An
> institution needing its founding myth unchallenged = antagonistic force.
> A character whose identity rests on a false history has an All Is Lost
> moment waiting.

## Social & Power Architecture

- Power structure — who's in charge, how power is held/transferred
- Class/caste system — rigidity, visibility, official vs actual justification
- Institutions — organizations enforcing the world's Laws
- Fault lines — tensions/injustices/fractures the story may exploit/expose
- Whose truth is official — whose version of history/morality/law is default
- Protagonist's position at story open
- Position arc — how it changes across the story

## World State Snapshots (at each of the 5 pillars)

| Pillar | World State Question |
|---|---|
| Story Open | Baseline condition — what does normal look like? |
| Inciting Incident | What does the disruption reveal/do to world's state? Was normal already fragile? |
| Plot Point 1 | What world does protagonist commit to entering? |
| Midpoint | What's revealed about world's true condition that was hidden? |
| All Is Lost | World at its darkest — what's been lost/broken at scale? |
| Climax/Close | Transformed, restored, or deliberately unchanged? What does that say? |

> The delta between world-open and world-close is the world's arc. When it
> mirrors the protagonist's arc, it amplifies theme. When it deliberately
> doesn't, that gap IS the theme.

## Cross-Layer Connections

| Connection | Direction | What Is Shared |
|---|---|---|
| Character — Lie/Truth/Wound | Bidirectional | Character Lies often mirror World Lies; world revelation can trigger character reckoning |
| Character — Social Position | World → Character | Protagonist's power-architecture position shapes character atoms |
| Plot — Laws | World → Plot | Specific Laws generate pillar-point plot pressure; exploitable Laws = plot engine candidates |
| Plot — World State Snapshots | Bidirectional | Pillar positions inform snapshot timing; snapshots feed consequence assessment |
| Relationships — Institutions | World → Relationships | Institutional power shapes who has leverage over whom |
| Theme Layer | World → Theme | Atmosphere, tone, symbolic resonance, truth/believed gaps all feed Theme |
| Timeline Layer | World → Timeline | Historical records + state snapshots = temporal scaffolding |
| Chapter Draft System | World → Output | Location registers, active Laws, world state at scene-time injected into prompts |
